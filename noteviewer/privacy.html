개인정보처리방침

시행일: 2026년 10월 31일 · 앱: 노트 뷰어 (Note Viewer)

1. 요약

노트 뷰어는 사용자의 Google 드라이브에 있는 PDF 노트(또는 사용자가 추가한 GitHub 공개 저장소의 PDF)를 읽기 전용으로 불러와 휴대폰에서 보여 주는 앱입니다. 모든 데이터는 사용자의 기기 안에서만 처리됩니다. 개발자가 운영하는 서버는 없으며, 노트와 Google 드라이브 데이터는 개발자나 제3자에게 전송되지 않습니다. 광고, 분석(애널리틱스), 추적 도구를 사용하지 않습니다(필기 검색을 켠 경우 4항의 Google ML Kit 진단 정보는 예외). GitHub 저장소를 추가하면 4항처럼 GitHub가 요청을 받습니다.

2. 접근하는 정보

  • Google 계정 기본 정보: 연결된 계정의 이메일 주소와 이름. 설정 화면에 어느 계정이 연결됐는지 표시하는 데만 씁니다.
  • Google 드라이브 파일: 사용자가 고른 노트 폴더 안의 폴더 이름, PDF 파일 이름, 수정 시각, 크기, 파일 내용. 노트 목록을 만들고 PDF를 화면에 표시하며, 앱 안의 기능(검색, 장 목록, 바뀐 페이지 표시, 암기 모드)에 기기 안에서만 씁니다. 드라이브의 파일을 수정하거나 삭제하지 않습니다.
  • 노트 폴더 찾기와 변경 확인: 노트 폴더를 추천하고 새로 바뀐 노트를 찾기 위해, 드라이브의 다른 위치에 있는 파일과 폴더의 이름, 종류, 크기, 위치(상위 폴더), 수정 시각, 미리보기 이미지 주소도 읽습니다. Google 드라이브는 바뀐 항목을 노트 폴더만이 아니라 드라이브 전체에 대해 알려 주기 때문입니다. 이 정보는 기기 안에서만 처리하며, 고른 노트 폴더에 속한 항목만 보관하고 나머지는 저장하지 않습니다. 다른 위치의 파일 내용은 읽지 않습니다.
  • 여러 계정·폴더(Android 앱): 노트 폴더를 여러 개 연결하거나 다른 Google 계정을 추가하면, 각 계정에서 위와 같은 방식으로 고른 폴더만 읽습니다. 계정마다 연결 해제할 수 있습니다.
  • GitHub 공개 저장소(선택): 사용자가 주소를 입력한 공개 저장소의 PDF 파일 이름, 경로, 크기, 내용과 최신 커밋·릴리스 정보. 로그인하지 않으며 GitHub 계정이나 비공개 저장소에는 접근하지 않습니다.
  • 사용자가 직접 가져온 PDF: 휴대폰에서 고르거나 다른 앱에서 공유한 PDF 파일.

3. 저장 위치와 보관 기간

  • 오프라인 열람을 위해 PDF 사본, 표지 이미지, 검색용 텍스트, 개요가 없는 PDF에서 자동으로 찾은 장(章) 목록, 새 버전에서 바뀐 페이지를 찾기 위한 페이지별 지문(그림이 아닌 짧은 숫자), 설정(즐겨찾기, 책갈피, 마지막으로 본 페이지 등)을 앱 내부 저장소에만 보관합니다.
  • 보관된 데이터는 사용자가 삭제할 때까지 유지됩니다. 설정 → 오프라인 사본 모두 삭제나 앱 삭제로 언제든 지울 수 있습니다. 연결 해제는 드라이브 접근 권한과 백그라운드로 받아 둔 파일을 지우지만, 이미 열어 본 노트의 오프라인 사본은 위 방법으로 지울 때까지 남습니다. 추가한 GitHub 저장소는 Google 연결 해제와 상관없이 남으며, 설정 → GitHub에서 뺄 수 있습니다.
  • 백그라운드 동기화(Android 앱, 기본으로 켜져 있으며 설정에서 끌 수 있음): 앱이 닫혀 있어도 약 15분마다 Google 드라이브의 변경 기록을 확인해 노트 폴더의 새 노트를 찾고, 바뀐 PDF를 앱 내부 저장소에 미리 받아 둡니다(기본 설정에서는 Wi‑Fi에서만). 이때 Google 드라이브의 데이터는 드라이브와 기기 사이에서만 오갑니다. 업데이트 알림은 알림 권한을 허용한 경우에만 표시됩니다. GitHub 저장소를 추가했다면 같은 때에 그 저장소의 최신 커밋과 릴리스도 확인해 바뀐 PDF를 알려 줍니다.
  • 추가한 GitHub 저장소의 주소는 앱 설정에 보관되며, 설정 → GitHub에서 저장소를 빼면 그 저장소의 노트 목록, 오프라인 사본, 필기 인식 결과, 장 목록과 바뀐 페이지 지문도 지워집니다.
  • 필기 검색(Android 앱, 기본으로 꺼져 있음): 켜면 노트 페이지 이미지를 휴대폰 안에서 Google ML Kit 글자 인식으로 읽고, 인식된 글자와 그 위치를 검색용으로 앱 내부 저장소에 보관합니다. 페이지 이미지와 인식된 글자는 기기 밖으로 보내지 않습니다. 기능을 끄면 인식 결과와, 인식한 글자로 찾은 장 목록도 지워집니다.
  • 홈 화면 위젯(Android 앱, 사용자가 홈 화면에 추가한 경우): 최근에 읽은 노트 3개의 이름과 페이지, 첫 노트의 첫 페이지 그림을 위젯에 보여 주기 위해 앱 내부 저장소에 보관합니다. 위젯은 홈 화면을 보는 누구에게나 보이므로, 보이지 않게 하려면 위젯을 홈 화면에서 지우세요.
  • 앱 데이터는 Android 백업이나 기기 간 이전에 포함되지 않습니다.
  • Google 로그인 토큰은 Android의 Google Play 서비스가 관리하며, 앱은 짧게 유지되는 접근 토큰만 기기 안에 보관합니다.

4. 제3자 제공 및 전송

개인정보를 판매하거나 제3자에게 제공하지 않습니다. 앱은 파일을 불러오기 위해 Google의 서버(Google 로그인과 Google 드라이브 API)와 통신하며, 이 통신은 암호화(HTTPS)됩니다.

GitHub 저장소를 추가하면 앱이 GitHub의 서버(api.github.com, raw.githubusercontent.com, github.com 등)에 HTTPS로 직접 요청합니다. 이때 GitHub는 일반적인 웹 요청처럼 기기의 IP 주소, 요청한 저장소·파일 주소, 그리고 기기 종류와 Android·앱 버전을 알려 주는 일반 요청 정보(User-Agent, 언어 설정)를 받으며, GitHub 개인정보처리방침이 적용됩니다. 노트, Google 계정 정보, Google 드라이브 데이터는 GitHub로 보내지 않습니다.

필기 검색을 켜면 글자 인식을 제공하는 Google Play 서비스의 ML Kit가 처음 쓸 때 인식 모델(앱 언어가 일본어·중국어면 그 언어용, 그 밖에는 한국어·라틴 문자용)을 받고, Google의 ML Kit 데이터 공개 문서에 따라 진단과 사용 통계를 위한 기기·앱 정보와 성능 지표를 암호화해 Google에 보낼 수 있습니다. 노트 페이지 이미지와 인식된 글자는 보내지 않습니다.

5. Google API 서비스 사용자 데이터 정책 준수

노트 뷰어가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 포함하여 해당 정책을 준수합니다. Google 사용자 데이터는 범용 인공지능(AI)·머신러닝 모델을 개발, 개선 또는 학습시키는 데 사용하지 않습니다. 필기 검색으로 페이지에서 인식한 글자는 앱 안의 검색에만 쓰이며 기기 밖으로 나가지 않습니다(이미 학습된 기기 안의 모델로 인식할 뿐, 모델을 학습시키지 않습니다).

6. 권한 철회

앱의 설정 → 연결 해제를 누르면 Google에 권한 철회를 요청합니다(계정을 여러 개 연결했다면 계정마다 따로 해제할 수 있습니다). 인터넷 연결 문제 등으로 Google이 철회를 확인하지 못하면 앱이 알려 드리며, 이때나 언제든 Google 계정의 연결된 앱 관리에서 ‘노트 뷰어’를 삭제해 접근 권한을 직접 철회할 수 있습니다.

이 앱은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

Privacy Policy

Effective: October 31, 2026 · App: Note Viewer

1. Summary

Note Viewer shows PDF notes stored in your Google Drive (or PDFs in public GitHub repositories you add) on your phone, with read-only access. All data is processed on your device only. There is no developer-operated server, and your notes and Google Drive data are never sent to the developer or to third parties. The app contains no ads, analytics or tracking (except the Google ML Kit diagnostics in section 4 when handwriting search is on). If you add GitHub repositories, GitHub receives the requests as described in section 4.

2. Information the app accesses

  • Basic Google account info: the email address and name of the connected account, used only to show which account is connected.
  • Google Drive files: folder names, PDF file names, modification times, sizes and file contents inside the notes folder you choose, used only on your device to build your note list, display PDFs, and power in-app features (search, chapter lists, changed-page marks, memorize mode). The app never modifies or deletes files in your Drive.
  • Finding the notes folder and detecting changes: to suggest a notes folder and find notes that changed, the app also reads the names, types, sizes, locations (parent folders), modification times and thumbnail links of files and folders elsewhere in your Drive, because Google Drive reports changes for your whole Drive, not just the notes folder. This is processed on the device only; just the items in the chosen notes folders are kept. The content of files elsewhere is not read.
  • Several folders and accounts (Android app): if you connect more notes folders or add another Google account, the app reads only the folders you chose in each account, in the same way. Each account can be disconnected on its own.
  • Public GitHub repositories (optional): file names, paths, sizes and contents of the PDFs in public repositories whose address you enter, and their latest commit and release. The app doesn't sign in and never accesses your GitHub account or private repositories.
  • PDFs you import: PDF files you pick on your phone or share to the app from other apps.

3. Storage and retention

  • For offline reading, PDF copies, cover images, search text, chapter lists found automatically in PDFs without an outline, a short per-page fingerprint (a number, not an image) to find the pages that changed in a newer version, and settings (favorites, bookmarks, last read page, etc.) are stored only in the app's private storage.
  • This data stays until you delete it with Settings → Delete all offline copies or by uninstalling the app. Disconnecting removes Drive access and the files fetched in the background, but offline copies of notes you already opened stay until you delete them as above. GitHub repositories you added stay after disconnecting Google; remove them in Settings → GitHub.
  • Background sync (Android app, on by default, can be turned off in Settings): even while the app is closed, it checks Google Drive's change history about every 15 minutes to find new notes in your notes folder, and downloads updated PDFs into the app's private storage (on Wi‑Fi only by default). Google Drive data still only travels between Google Drive and your device. Update notifications appear only if you allow notifications. If you added GitHub repositories, their latest commit and release are checked at the same time to tell you about changed PDFs.
  • The addresses of the GitHub repositories you add are kept in the app's settings; removing a repository in Settings → GitHub also deletes its note list, offline copies, handwriting results, chapter lists and page fingerprints.
  • Handwriting search (Android app, off by default): when you turn it on, note page images are read on the phone with Google ML Kit text recognition, and the recognized text and its position are kept in the app's private storage for search. Page images and recognized text never leave the device. Turning the feature off deletes the results, including chapter lists found from recognized handwriting.
  • Home screen widget (Android app, if you add it to your home screen): the names and pages of the three notes you read last, and a picture of the first one's first page, are kept in the app's private storage to show them in the widget. Anyone who sees your home screen can see the widget; remove it from the home screen to stop showing it.
  • App data is excluded from Android backups and device-to-device transfers.
  • Google sign-in is managed by Google Play services on Android; the app only keeps short-lived access tokens on the device.

4. Sharing

We do not sell or share personal information. To load your files, the app communicates with Google's servers (Google sign-in and the Google Drive API) over encrypted HTTPS.

If you add GitHub repositories, the app sends requests directly to GitHub's servers (api.github.com, raw.githubusercontent.com, github.com and similar) over HTTPS. Like any web request, GitHub receives your device's IP address, the addresses of the repositories and files requested, and standard request information such as the user agent (device type, Android and app version) and language setting, and the GitHub Privacy Statement applies. Your notes, Google account information and Google Drive data are never sent to GitHub.

If you turn on handwriting search, ML Kit in Google Play services, which provides the text recognition, downloads the recognition model the first time it is used (a Japanese or Chinese one when the app is in that language, otherwise Korean and Latin letters) and, as described in Google's ML Kit data disclosure, may send device and app information and performance metrics (encrypted) to Google for diagnostics and usage analytics. Note page images and recognized text are not sent.

5. Google API Services User Data Policy

Note Viewer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used to develop, improve or train generalized artificial intelligence (AI) or machine learning models. Text recognized from your pages by handwriting search is used only for search inside the app and never leaves the device (a pre-trained on-device model reads it; no model is trained).

6. Revoking access

Tap Settings → Disconnect in the app, which asks Google to revoke the app's access (with several accounts, each can be disconnected on its own). If Google can't confirm it (for example, while offline), the app tells you; then, or at any time, remove “노트 뷰어” (Note Viewer) at your Google Account's connected apps.

7. Children

The app is not directed at children and does not knowingly collect children's personal information.
